# ДПО-1 · Урок 4

Публичный интерактивный урок на 180 минут:

**«Подготовка информации для работы с ИИ. Правовые и репутационные риски применения ИИ»**

Страница: https://smit1980.github.io/DPO-1_4/

## Состав

- две пары по 90 минут, четыре академических блока;
- полный сценарий преподавателя в переключаемом режиме;
- 10 интерактивов и статические пояснения;
- устойчивые места под 30 слайдов;
- локальные формы паспорта задачи и карты риска;
- четыре скачиваемых шаблона;
- официальные источники с датой проверки.

Все примеры синтетические. Материалы не заменяют внутренние правила организации, оценку информационной безопасности или юридическое заключение.

## Слайды

Страница ожидает файлы assets/slides/slide_001_v2.png … slide_030_v2.png. Если файл отсутствует, отображается тематический плейсхолдер. Для обновления достаточно добавить PNG с ожидаемым именем и опубликовать изменения.
