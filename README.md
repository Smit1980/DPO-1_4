# ДПО-1 · Урок 4

Интерактивный урок «Подготовка информации для работы с ИИ. Правовые и репутационные риски применения ИИ».

Страница: https://smit1980.github.io/DPO-1_4/web/urok4_podgotovka_i_riski.html

## Структура

- Пара 1: 0–90 минут. Первые 45 минут — повторение, далее подготовка данных и настройки.
- Перерыв после 90 учебных минут.
- Пара 2: 90–180 минут. Авторское право, синтетический контент, ошибки и предвзятость, дипфейки, ответственность.
- 9 блоков, 30 слайдов с текстовыми пояснениями, 9 практик.
- GigaChat, DeepSeek, ChatGPT: одинаковые учебные входы; 3 основных живых сравнения.
- Реальные открытые кейсы отделены от синтетических упражнений.
- Обзор программ-анонимизаторов хранится отдельно и НЕ включён до подтверждения.

Генерировать следует по НОВЫМ промптам V3, содержащим русский текст и пояснения внутри изображения. Один прежний тестовый PNG помечен как тестовый; остальные изображения добавляются по готовности. Пояснения к каждому слайду доступны и без PNG.

## Источник и сборка

content/sections/s1.json … s9.json — канонический учебный текст.
content/slide-specs.json — короткие подписи и композиции инфографики.
build_materials.py собирает lesson.json, конспекты и тетрадь.
build_samples.py генерирует только синтетические CSV/XLSX/DOCX.
build_prompts.py собирает 30 промптов и проверяет ZIP.
build_lesson.py генерирует статический HTML. Браузер не обращается к AI API.

Порядок локальной сборки:
1. python build_materials.py
2. python build_samples.py
3. python build_prompts.py
4. python build_lesson.py
5. python -m unittest discover -s tests -p "check_*.py" -v

Для генерации DOCX/XLSX нужны python-docx и openpyxl (в поставляемой среде Codex уже доступны). Для просмотра достаточно статического HTTP-сервера, привязанного к 127.0.0.1. Для браузерных smoke-тестов — Playwright из подготовленной среды, без установки новых зависимостей.

## Границы

Кейсы подтверждены указанными источниками, но урок не заменяет юридическое заключение или правила организации. Нет оценки реальных сотрудников и закрытых производственных данных. Учебные ответы не выдаются за фактические результаты моделей. Доступ к ChatGPT/видео проверяется преподавателем в своей сети заранее. Обучение не предлагает обходить корпоративные ограничения.
