# ДПО-1 · Урок 4 · Подготовка информации для ИИ и правовые риски

Страница для слушателей: https://smit1980.github.io/DPO-1_4/web/urok4_podgotovka_i_riski.html

Две пары по 90 минут:
- **Пара 1** (блоки 1–6): что уходит вместе с файлом, метаданные, обезличивание, условные данные и шаблоны запросов, история и настройки хранения, паспорт безопасной задачи.
- **Пара 2** (блоки 7–11): авторское право, недостоверные сведения, предвзятость, дипфейки, ответственность пользователя.

Примеры — реальные опубликованные случаи со ссылками на источники и вымышленные учебные данные. Три модели для показа: GigaChat, DeepSeek, ChatGPT. Материал не заменяет политику информационной безопасности Концерна ВКО «Алмаз – Антей» и локальные акты предприятия.

## Состав страницы
Обзорный слайд 00 и слайды 21–23 (открытие, пара 2, итог), 20 основных слайдов с пояснениями, углублённые разборы блоков, каталог подделок и дипфейков, раздел практикума 1.3 (кейсы с копируемыми запросами), 20 промптов и домашнее задание внизу страницы. Файлы для скачивания: Excel-памятка, презентация PPTX/PDF, памятки, пакет промптов (docx, xlsx, csv, json, txt).

## Сборка (локально)
```
py tools/build_files.py          # учебные файлы, памятки, zip → data/
py tools/build_slides.py         # png/urok4/00.png, 1.png … 27.png → png/urok4_podgotovka_i_riski/*.jpg
py tools/build_page.py           # страница и демо → web/
py -m unittest discover -s tests -p "check_*.py"
```
Слайды: положите PNG `1.png … 20.png` в `png/urok4/`, запустите `build_slides.py` и `build_page.py`. Пока картинок нет, страница показывает заглушки; пояснения к слайдам уже на месте.

Материалы преподавателя (конспект) в этот репозиторий не входят: они публикуются отдельно в DPO-1_konspekt.
