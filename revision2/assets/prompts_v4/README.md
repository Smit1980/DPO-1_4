Откройте в масштабе показа: все карточки читаемы, кириллица без ошибок, примеры совпадают с текстом урока, логотипы и подписи не подменены. Если повреждена надпись, исправьте конкретную область генератором; не принимайте изображение только за цветовую похожесть.
