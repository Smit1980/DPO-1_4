# Урок 7 · Вторая пара

Интерактивный материал: «Составление и доработка рабочих материалов с помощью ИИ. Мультимодальные возможности ИИ: работа с текстом, изображениями, аудио и файлами».

- `index.html` — страница для слушателей.
- `teacher.html` — отдельный конспект преподавателя.
- `assets/slides/` — 14 визуальных слайдов, встроенных в оба маршрута занятия.
- `data/Синтетика_Урок7/` — 22 учебных исходника для практики и отдельная страница загрузок.

В публичную версию намеренно не включены разборы, ответы к заданиям, полный архив раздатки и внутренние материалы.
