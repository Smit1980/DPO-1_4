# Синтетика · Урок 7 · Вторая пара

Эта папка собрана для учебной демонстрации загрузки файлов в ИИ. Во всех сценариях организации, сотрудники, показатели, сроки, заявки и исходные обстоятельства вымышлены.

Используйте для показа только файлы из папок `01_Основной_кейс`, `02_Дополнительные_кейсы` и `03_Домашняя_работа`. Не добавляйте к ним реальные внутренние документы, персональные данные или сведения ограниченного доступа.

В эту папку намеренно не включены разборы преподавателя, реестр открытых источников, рыночная выборка и шаблоны итоговых решений: они нужны для проверки методики, а не как исходник для первого запроса.

## Состав

- `01_Основной_кейс` — заявка, таблица расхода, учебная этикетка, ТЗ и текст для диктовки.
- `02_Дополнительные_кейсы` — четыре независимых исходника для тренировки.
- `03_Домашняя_работа` — четыре исходника для самостоятельного повторения.

После ответа ИИ сверяйте факты с исходным файлом, сохраняйте запрос и отмечайте, что требует уточнения человеком.
