## Куда положить готовые слайды

Рабочая папка приёма: C:\2026 программы\cloude code\аЛМАЗ аНТЕЙ\DPO-1_4\assets\slides

Имена: slide_001_v2.png … slide_030_v2.png. Суффикс v2 оставлен только ради совместимости существующих адресов HTML; содержание генерируется по V3.

Сайт не следит за диском автоматически. После проверки текста и замены файлов требуется отдельный commit/push и успешная сборка GitHub Pages. Массовую генерацию или загрузку картинок этот пакет не выполняет.

Промпты 001–010 относятся к первой группе слайдов; пакет не равен паре. Граница двух пар проходит между слайдами 021 и 022.

## Проверка готового PNG

Откройте в масштабе показа: все карточки читаемы, кириллица без ошибок, примеры совпадают с текстом урока, логотипы и подписи не подменены. Если повреждена надпись, исправьте конкретную область генератором; не принимайте изображение только за цветовую похожесть.
